# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in Legends Ultimate
Captions, please send an advisory email directly to:

`advisory@cto-legends.com`

Please include:

- Description of the vulnerability and impact.
- Steps to reproduce or proof-of-concept.
- Operating system and Python version.

We appreciate responsible disclosure. We aim to acknowledge reports within
2 business days and share a remediation timeline within 5 business days.

## Sensitive Material

Do not open public issues with credentials, private media paths, signed
URLs, member data, receipts, API keys, or model access tokens.
