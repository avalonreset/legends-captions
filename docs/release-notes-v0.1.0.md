# v0.1.0 Release Notes

Legends Ultimate Captions v0.1.0 is the first public release of the standalone
caption system.

## Included

- Context-aware caption correction engine.
- CLI commands for doctor, policy report, and text normalization.
- ASS document helper functions.
- Correction manifest helper.
- Config seed for vertical 4K active-word captions.
- Glossary seed for LoRA, Seedance 2.0, RTX 4090, HeyGen, and SoulX FlashFace.
- Regression tests based on real caption QA corrections.
- Codex, Claude, Gemini, and portable Agent Skills adapters.
- Obsidian-style project brain.
- Skool launch drafts and release art staging.

## Not Yet Included

- Full video intake command.
- Automatic Parakeet orchestration.
- Automatic NFA orchestration.
- Full ASS active-word render package runner.
- ffprobe and proof-frame generation as one command.

Those are the next implementation phase.
