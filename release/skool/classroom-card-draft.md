# Legends Captions Classroom Card Draft

## Title

Legends Captions

## Body

Private agent-driven caption deployment system for accurate video captions.

This is the caption workflow for videos where generic auto captions are not good enough.

What it handles:

- context-aware ASR correction
- model names, acronyms, domains, and hardware names
- active-word caption policy
- forced-alignment timing standards
- correction manifests
- proof-frame QA
- revision memory that turns fixes into tests
- Codex, Claude, and Gemini agent surfaces
