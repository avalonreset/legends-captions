# Spoken Acronym Timing

When the speaker spells a term, the caption can be more faithful if each letter has its own highlight timing.

Example: `L O R A`

Preferred behavior:

- keep the displayed letters separated if that reads naturally;
- highlight `L`, then `O`, then `R`, then `A`;
- use NFA letter timing when available;
- otherwise distribute virtual letter timing across the aligned acronym span and mark it in the manifest.
